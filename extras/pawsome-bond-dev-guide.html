🧠 The Bonding Algorithm

This is THE MAGIC - how we measure emotional connection between human and dog.

⚠️
Critical: The algorithm runs every 5 seconds during a bonding session and needs at least 60 seconds of data for accurate synchronization measurement.

Step 1: Data Collection (Every 5 seconds)

Human Data: - Heart Rate (HR): 60-100 BPM typical - HRV (RMSSD): 20-100 ms typical - Timestamp: Date.now() Dog Data: - Heart Rate (HR): 80-120 BPM typical (hunter breed) - HRV (RMSSD): 20-80 ms typical - Respiratory Rate: 10-30 breaths/min - Timestamp: Date.now()

Step 2: Calculate Individual Coherence (0-100)

Human Coherence Formula ▼
Human Coherence = (HRV Score × 0.7) + (Resting HR Score × 0.3) Where: - HRV Score = min(HRV / 100, 1.0) × 100 Higher HRV = More calm/coherent - Resting HR Score = max(0, (100 - HR) / 40) × 100 Lower resting HR = More calm Typical: 60-100 BPM 
function calculateHumanCoherence(hrv, heartRate) {
  // Normalize HRV (typical range: 20-100ms)
  const normalizedHRV = Math.min(hrv / 100, 1.0) * 100;
  
  // Lower resting HR = more calm (typical: 60-100 BPM)
  const restingScore = Math.max(0, (100 - heartRate) / 40 * 100);
  
  // Weighted average
  return (normalizedHRV * 0.7) + (restingScore * 0.3);
}

Example: HR=72, HRV=65 → Coherence = 85.5

Dog Coherence Formula ▼
Dog Coherence = (HRV × 0.5) + (Resting HR × 0.3) + (Breathing × 0.2) Where: - HRV Score = min(HRV / 80, 1.0) × 100 Hunter dogs: typically 20-80ms - Resting HR Score = max(0, (140 - HR) / 80) × 100 Hunter dogs: typically 80-120 resting - Breathing Score = max(0, (30 - RespRate) / 20) × 100 Normal: 10-30 breaths/min Higher = more stressed 
function calculateDogCoherence(hrv, heartRate, respiratoryRate) {
  // Normalize dog HRV (typical range: 20-80ms)
  const normalizedHRV = Math.min(hrv / 80, 1.0) * 100;
  
  // Dog resting HR: 60-140 BPM depending on size/breed
  // Hunter dogs: ~80-120 resting
  const restingScore = Math.max(0, (140 - heartRate) / 80 * 100);
  
  // Respiratory rate: 10-30 breaths/min normal
  // Higher = more stressed
  const breathScore = Math.max(0, (30 - respiratoryRate) / 20 * 100);
  
  // Weighted average
  return (normalizedHRV * 0.5) + (restingScore * 0.3) + (breathScore * 0.2);
}

Example: HR=95, HRV=42, RespRate=28 → Coherence = 78.3

Step 3: Calculate Synchronization Quality (0-100)

✨
This measures if the heart rhythms are syncing between human and dog - the core of emotional bonding!
Synchronization = Cross-Correlation of HRV patterns Requirements: - Need at least 12 data points (60 seconds @ 5-sec intervals) - Compare HRV wave patterns with time shifts (-5 to +5 seconds) - Find maximum correlation score 
function calculateSynchronization(humanHRVArray, dogHRVArray) {
  // Need at least 12 data points (1 minute of data)
  if (humanHRVArray.length < 12 || dogHRVArray.length < 12) {
    return 0;
  }
  
  // Cross-correlation analysis
  let maxCorrelation = 0;
  
  // Try different time shifts (-1 to +1 intervals = -5 to +5 seconds)
  for (let shift = -1; shift <= 1; shift++) {
    let correlation = 0;
    let count = 0;
    
    for (let i = 0; i < humanHRVArray.length; i++) {
      const dogIndex = i + shift;
      if (dogIndex >= 0 && dogIndex < dogHRVArray.length) {
        // Normalize both values
        const humanNorm = humanHRVArray[i] / 100;
        const dogNorm = dogHRVArray[dogIndex] / 80;
        
        // Calculate similarity (1 - difference)
        correlation += (1 - Math.abs(humanNorm - dogNorm));
        count++;
      }
    }
    
    if (count > 0) {
      const avgCorrelation = (correlation / count) * 100;
      maxCorrelation = Math.max(maxCorrelation, avgCorrelation);
    }
  }
  
  return Math.min(maxCorrelation, 100);
}

Step 4: Calculate Final Bond Score (0-10)

Bond Score = ((Human Coherence × 0.30) + (Dog Coherence × 0.30) + (Sync × 0.25) + Duration Bonus) / 10 Duration Bonus: - Max bonus at 15 minutes - Bonus = min(durationMinutes / 15, 1.0) × 15 - Longer sessions = slightly better scores 
function calculateBondScore(humanCoherence, dogCoherence, syncQuality, sessionDuration) {
  // Weighted formula
  const coherenceScore = (humanCoherence * 0.30) + (dogCoherence * 0.30);
  const syncScore = syncQuality * 0.25;
  
  // Duration bonus (longer sessions = slightly better)
  // Max bonus at 15 minutes
  const durationMinutes = sessionDuration / 60;
  const durationBonus = Math.min(durationMinutes / 15, 1.0) * 15;
  
  // Combine (max 100)
  const totalScore = coherenceScore + syncScore + durationBonus;
  
  // Convert to 0-10 scale
  return Math.min(totalScore / 10, 10.0);
}

  85,  // Human coherence: 85/100 (calm)
  78,  // Dog coherence: 78/100 (calm)
  88,  // Sync quality: 88/100 (high sync)
  600  // 10 minutes
);
// Result: 8.95/10 ⭐⭐⭐⭐⭐

import { BleManager } from 'react-native-ble-plx';

const bleManager = new BleManager();

// UUIDs - Update these with actual RunmefitSDK values
const RUNMEFIT_SERVICE = '0000fee0-0000-1000-8000-00805f9b34fb';
const HR_CHARACTERISTIC = '0000fee1-0000-1000-8000-00805f9b34fb';
const HRV_CHARACTERISTIC = '0000fee2-0000-1000-8000-00805f9b34fb';

// Scan for devices
async function scanForDevices() {
  bleManager.startDeviceScan(null, null, (error, device) => {
    if (error) {
      console.error(error);
      return;
    }
    
    // Look for Runmefit devices
    if (device.name && device.name.includes('GTS10')) {
      console.log('Found human device:', device.id);
      connectHumanDevice(device);
    } else if (device.name && device.name.includes('GTL')) {
      console.log('Found dog device:', device.id);
      connectDogDevice(device);
    } else if (device.name && device.name.includes('Vest')) {
      console.log('Found vest:', device.id);
      connectVest(device);
    }
  });
}

// Connect to human device
async function connectHumanDevice(device) {
  try {
    const connected = await device.connect();
    await connected.discoverAllServicesAndCharacteristics();
    
    // Subscribe to heart rate
    connected.monitorCharacteristicForService(
      RUNMEFIT_SERVICE,
      HR_CHARACTERISTIC,
      (error, characteristic) => {
        if (error) {
          console.error('HR monitoring error:', error);
          return;
        }
        
        const hrData = parseHeartRate(characteristic.value);
        updateHumanHeartRate(hrData);
      }
    );
    
    // Subscribe to HRV
    connected.monitorCharacteristicForService(
      RUNMEFIT_SERVICE,
      HRV_CHARACTERISTIC,
      (error, characteristic) => {
        if (error) {
          console.error('HRV monitoring error:', error);
          return;
        }
        
        const hrvData = parseHRV(characteristic.value);
        updateHumanHRV(hrvData);
      }
    );
    
    console.log('Human device connected successfully');
  } catch (error) {
    console.error('Connection failed:', error);
  }
}

// Parse heart rate from base64
function parseHeartRate(base64Data) {
  const buffer = Buffer.from(base64Data, 'base64');
  // Check RunmefitSDK documentation for actual format
  return buffer[1]; // Example - actual format may differ
}

// Parse HRV from base64
function parseHRV(base64Data) {
  const buffer = Buffer.from(base64Data, 'base64');
  // Check RunmefitSDK documentation for actual format
  return parseInt(buffer.toString('hex'), 16);
}
DC Mining Calculation ▼ 
// DC Mining Formula
function calculateDCMined(bondScore, sessionDuration, tierMultiplier = 5) {
  // Base DC = 2 DC per minute
  const baseDC = (sessionDuration / 60) * 2;
  
  // Quality multiplier based on bond score
  const qualityMultiplier = bondScore / 10;
  
  // Apply tier multiplier (Genesis = 5x, Pioneer = 3x, etc.)
  const dcEarned = baseDC * qualityMultiplier * tierMultiplier;
  
  return Math.round(dcEarned * 100) / 100; // Round to 2 decimals
}

Session Storage with AsyncStorage ▼ 
import AsyncStorage from '@react-native-async-storage/async-storage';

// Save session after completion
async function saveSession(sessionData) {
  try {
    // Get existing sessions
    const sessionsJSON = await AsyncStorage.getItem('sessions');
    const sessions = sessionsJSON ? JSON.parse(sessionsJSON) : [];
    
    // Add new session
    sessions.unshift({
      id: Date.now(),
      timestamp: new Date().toISOString(),
      bondScore: sessionData.bondScore,
      duration: sessionData.duration,
      dcEarned: sessionData.dcEarned,
      humanAvgHR: sessionData.humanAvgHR,
      dogAvgHR: sessionData.dogAvgHR,
      syncQuality: sessionData.syncQuality
    });
    
    // Keep only last 50 sessions
    if (sessions.length > 50) {
      sessions.pop();
    }
    
    // Save back
    await AsyncStorage.setItem('sessions', JSON.stringify(sessions));
    
    // Update total DC mined
    const totalDC = sessions.reduce((sum, s) => sum + s.dcEarned, 0);
    await AsyncStorage.setItem('totalDCMined', totalDC.toString());
    
    console.log('Session saved successfully');
  } catch (error) {
    console.error('Failed to save session:', error);
  }
}

// Load sessions for display
async function loadSessions() {
  try {
    const sessionsJSON = await AsyncStorage.getItem('sessions');
    return sessionsJSON ? JSON.parse(sessionsJSON) : [];
  } catch (error) {
    console.error('Failed to load sessions:', error);
    return [];
  }
}

// Get total DC mined
async function getTotalDC() {
  try {
    const total = await AsyncStorage.getItem('totalDCMined');
    return total ? parseFloat(total) : 0;
  } catch (error) {
    console.error('Failed to get total DC:', error);
    return 0;
  }
}
ESP32 Vest Firmware (Arduino) ▼
⚠️
Upload this code to your NodeMCU ESP32 before testing the app.
#include <BLEDevice.h>
#include <BLEServer.h>
#include <BLEUtils.h>
#include <BLE2902.h>

// UUIDs (generate your own!)
#define SERVICE_UUID        "12345678-1234-5678-1234-56789abcdef0"
#define COMMAND_CHAR_UUID   "12345678-1234-5678-1234-56789abcdef1"
#define STATUS_CHAR_UUID    "12345678-1234-5678-1234-56789abcdef2"

// Pin definitions
#define RED_LIGHT_PIN 25
#define VIBRATION_PIN 26

BLEServer* pServer = NULL;
BLECharacteristic* pCommandCharacteristic = NULL;
BLECharacteristic* pStatusCharacteristic = NULL;
bool deviceConnected = false;

class ServerCallbacks: public BLEServerCallbacks {
    void onConnect(BLEServer* pServer) {
      deviceConnected = true;
      Serial.println("Device connected");
    };
    void onDisconnect(BLEServer* pServer) {
      deviceConnected = false;
      Serial.println("Device disconnected");
      BLEDevice::startAdvertising();
    }
};

class CommandCallbacks: public BLECharacteristicCallbacks {
    void onWrite(BLECharacteristic *pCharacteristic) {
      String value = pCharacteristic->getValue();
      
      if (value.length() > 0) {
        Serial.println("Command: " + value);
        
        if (value.indexOf("\"action\":\"comfort\"") > -1) {
          // Turn on red light
          if (value.indexOf("\"redlight\":true") > -1) {
            digitalWrite(RED_LIGHT_PIN, HIGH);
            Serial.println("Red light ON");
          }
          
          // Activate vibration
          if (value.indexOf("\"vibration\":\"gentle\"") > -1) {
            analogWrite(VIBRATION_PIN, 77); // 30%
          }
          
          delay(30000); // 30 seconds
          digitalWrite(RED_LIGHT_PIN, LOW);
          analogWrite(VIBRATION_PIN, 0);
          Serial.println("Comfort ended");
        }
        
        pStatusCharacteristic->setValue("active");
        pStatusCharacteristic->notify();
      }
    }
};

void setup() {
  Serial.begin(115200);
  pinMode(RED_LIGHT_PIN, OUTPUT);
  pinMode(VIBRATION_PIN, OUTPUT);
  
  BLEDevice::init("PawsomeVest");
  pServer = BLEDevice::createServer();
  pServer->setCallbacks(new ServerCallbacks());
  
  BLEService *pService = pServer->createService(SERVICE_UUID);
  
  pCommandCharacteristic = pService->createCharacteristic(
                            COMMAND_CHAR_UUID,
                            BLECharacteristic::PROPERTY_WRITE
                          );
  pCommandCharacteristic->setCallbacks(new CommandCallbacks());
  
  pStatusCharacteristic = pService->createCharacteristic(
                           STATUS_CHAR_UUID,
                           BLECharacteristic::PROPERTY_READ |
                           BLECharacteristic::PROPERTY_NOTIFY
                         );
  pStatusCharacteristic->addDescriptor(new BLE2902());
  
  pService->start();
  BLEDevice::getAdvertising()->start();
  
  Serial.println("Vest ready!");
}

void loop() {
  delay(1000);
}

🐛 Troubleshooting Guide

Issue: Devices Not Connecting ▼

Symptoms

Scanning finds no devices, connection times out, or devices disconnect immediately.

Solutions

  • Check Bluetooth is ON on phone (Settings → Bluetooth)
  • Verify devices are charged and powered on
  • Ensure devices are in pairing mode (check manual)
  • Try restarting all devices (including phone)
  • Check Android permissions granted:
    • BLUETOOTH
    • BLUETOOTH_ADMIN
    • ACCESS_FINE_LOCATION
  • Move closer to devices (within 5 meters)
  • Turn off other Bluetooth devices to reduce interference
  • Check device names match expected values (GTS10, GTL, Vest)
💡
Tip: Use a BLE scanner app (like nRF Connect) to verify devices are advertising.
Issue: Data Reading Errors ▼

Symptoms

Heart rate shows 0, garbage values, or doesn't update.

Solutions

  • Verify characteristic UUIDs match RunmefitSDK docs
  • Check base64 decoding is correct
  • Log raw characteristic data to console
  • Ensure devices have good skin contact (not loose)
  • Verify notification subscription is active
  • Check data parsing matches actual format
  • Try different service/characteristic combinations
// Debug logging
console.log('Raw characteristic value:', characteristic.value);
console.log('Base64 decoded:', Buffer.from(characteristic.value, 'base64'));
console.log('Parsed HR:', parseHeartRate(characteristic.value));
Issue: Bond Score Always Low ▼

Symptoms

Score stuck at 3-5/10 even during calm sessions.

Solutions

  • Verify HRV data is actually being received (not 0)
  • Check synchronization algorithm has enough data points (60+ seconds)
  • Lower threshold for "good" HRV values in normalization
  • Test in calm environment (no loud noises, distractions)
  • Verify both human and dog are actually calm (check HR values)
  • Adjust coherence weights if needed
  • Check duration bonus is being added correctly
💡
Debug: Log individual coherence scores and sync quality to see which component is low.
Issue: Vest Not Responding ▼

Symptoms

Comfort button does nothing, no red light or vibration.

Solutions

  • Check ESP32 is powered on (LED indicator)
  • Verify BLE connection to vest is active
  • Check command JSON format matches expected
  • Test with Serial Monitor on ESP32 (see if command received)
  • Verify GPIO pins are correct (25 = LED, 26 = Motor)
  • Check LED strip/motor are wired correctly
  • Test with direct GPIO write (bypass BLE)
  • Ensure base64 encoding is correct
// Test GPIO directly on ESP32
void loop() {
  digitalWrite(RED_LIGHT_PIN, HIGH);
  analogWrite(VIBRATION_PIN, 77);
  delay(3000);
  digitalWrite(RED_LIGHT_PIN, LOW);
  analogWrite(VIBRATION_PIN, 0);
  delay(3000);
}
Issue: App Crashes or Freezes ▼

Symptoms

App becomes unresponsive, crashes on certain actions, or memory issues.

Solutions

  • Check console for error messages
  • Verify async operations have proper error handling
  • Ensure BLE subscriptions are cleaned up on unmount
  • Check for memory leaks (listeners not removed)
  • Verify state updates are not causing infinite loops
  • Test on device instead of simulator (better performance)
  • Clear app cache and restart
  • Check for null/undefined access errors
// Proper cleanup
useEffect(() => {
  const subscription = bleManager.onDeviceDisconnected(...);
  
  return () => {
    // Cleanup on unmount
    subscription.remove();
    bleManager.stopDeviceScan();
  };
}, []);
